# Travel Hack Global — Brand Assets

Public reference assets for Travel Hack Global AI image generation and creative production.

**Public URL base:**
`https://raw.githubusercontent.com/contextarchitect/brand-assets/main/travel-hack-global/`

## Folder Structure

| Folder | Contents | REF Range |
|--------|----------|----------|
| `brand-identity/` | Logo files, colour swatches, typography | REF-001 to REF-002 |
| `ui-screenshots/` | Platform UI screenshots incl. price comparison | REF-003 to REF-009 |
| `destination-scenes/` | Aspirational travel imagery examples | REF-010+ |

## Asset Priority Order

1. TravelHack logo (brand-identity/) — REQUIRED before any ad creative
2. Price comparison screenshot with parody OTA names (ui-screenshots/) — REQUIRED before angles 1 and 2
3. Other UI screenshots
4. Destination scene examples

## Visual Rules (Summary)

- NEVER show real hotel names, logos, or branded signage in any image
- Focus on cityscapes, skylines, nature, and aspirational destination scenes
- Any price comparison UI must show parody OTA names (Billing.com, Expensivisa, Agotcha!) — never real OTA names
- Full visual rules: see `context-architect-brands/travel-hack-global/platform-adaptation.md`

## Upload Instructions

1. Go to the relevant subfolder
2. Click **Add file** > **Upload files**
3. Drag and drop files
4. Commit directly to `main`
5. Notify the operator so REF codes can be assigned in `image-reference-index.md`

**Important:** This repo is public. Only upload assets cleared for external visibility.
