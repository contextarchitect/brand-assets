# Panther Eclipse - Product Images

Product reference images for AI image generation.

## Public URL Pattern

```
https://raw.githubusercontent.com/contextarchitect/brand-assets/main/panther/product-images/[filename]
```

## File Naming Convention

Files are named REF1.jpg through REF16.png, matching the Image Reference Index at:
`context-architect-brands/panther/image-reference-index.md`

## Usage

Always reference images by their full public URL when passing to external APIs (Kie, Nano Banana, Creative Engine). See the Image Reference Index for REF codes, scale context ratings, face design details, and recommended use cases.

## Important

This is a PUBLIC repository. Only upload product images already visible on the brand's website or in published ads. Never upload strategy documents, internal files, or unreleased product imagery.
