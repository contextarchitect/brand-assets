# Travel Hack Global — Brand Identity Assets

Logo files, colour system swatches, and typography specimens.

**Public URL pattern:**
`https://raw.githubusercontent.com/contextarchitect/brand-assets/main/travel-hack-global/brand-identity/[filename]`

## Expected Assets

| File | Description | REF Code | Priority |
|------|-------------|----------|----------|
| `logo-primary.png` | TravelHack full lockup (wordmark + pin-keyhole icon + tagline) | REF-001 | CRITICAL |
| `logo-icon.png` | Pin-keyhole icon only (for small formats / app icon) | REF-002 | HIGH |
| `logo-wordmark.png` | TravelHack wordmark only (for contexts where icon renders poorly) | REF-002b | MEDIUM |

## Brand Colours (for reference)

| Name | Hex | Role |
|------|-----|------|
| Teal | #0795A0 | Brand anchor — primary CTAs, icon, links |
| Navy | #022334 | Trust register — headers, primary typography |
| Sunset Orange | #FA904E | Emotional accent — Savings Promise, warm moments |
| Cream | #F0E7D8 | Editorial warmth — section backgrounds |
| Deep Teal | #045667 | Depth / hover states |

## Upload Instructions

Drag and drop files into this folder via GitHub UI. Commit to `main`.
Notify the operator once uploaded so REF-001 and REF-002 can be assigned in `image-reference-index.md`.

**Format requirements:** PNG with transparency preferred for logo files. Minimum 1000px on the longest edge.
