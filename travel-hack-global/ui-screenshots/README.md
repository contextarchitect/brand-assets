## Critical Rule: Parody OTA Names Only

The comparison screen (REF-003) is the single most important creative asset for this brand. It MUST show:
- Member rate in the Travel Hack column
- Public rate comparison in a column labelled with parody OTA names: **Billing.com**, **Expensivisa**, **Agotcha!**
- Real OTA names (Booking.com, Expedia, Agoda, etc.) must NEVER appear in any screenshot uploaded here

If the client provides a comparison screenshot with real OTA names, it must be edited to use parody names before uploading.

## Upload Instructions

Notify the operator once uploaded so REF codes can be assigned in `image-reference-index.md`.

**Format requirements:** PNG, actual device resolution preferred. If providing a designed mock-up, export at 2x / retina resolution.
